# WOMEN'S FOOTBALL GUIDE

女子サッカー選手名鑑サイトの静的プロトタイプです。

## ファイル
- `index.html` : ページ構造
- `style.css` : デザインとレスポンシブ対応
- `app.js` : 選手・チームデータ、検索、フィルター、プロフィールダイアログ、お気に入りUI
- `main-symbol.png` : サイトのメインシンボル
- `nishio-hanon.png` : 西尾葉音選手のユニフォーム画像
- `takahashi-hana.png` : 高橋はな選手のユニフォーム画像
- `hasegawa.png` : 長谷川唯選手のプロフィール欄に使用する画像（提供画像）

## 表示方法
3ファイルを同じフォルダに置き、`index.html` をブラウザで開いてください。外部APIやビルド作業は不要です。Google Fontsはネット接続時に読み込みます。

## 主な機能
- 選手名・読み・チーム名などで検索
- リーグ／ポジションで選手を絞り込み
- 選手カードからプロフィールとエピソードを表示
- お気に入りUI（ページを再読み込みするとリセットされます）
- WEリーグ／なでしこリーグ1部／2部のチーム検索
- 各リーグ公式ページへのリンク
- スマートフォン対応

## 公開前に必ず確認すること
- `app.js` の選手データはレイアウト確認用のサンプルを含みます。現在の所属、ポジション、経歴、エピソード、出典を個別に確認して更新してください。
- チーム一覧のリーグ区分も、公開直前に各公式サイトで再確認してください。
- 長谷川唯選手のプロフィール画像として `hasegawa.png` を組み込んでいます。公開前に、この画像のウェブ掲載・配布に必要な許諾、ライセンス、著作者表示・クレジット条件を確認してください。
- Wikipediaの文章を直接再利用する場合は、対象ページのライセンス条件と帰属表示・継承条件などを確認してください。独自の要約でも、重要な事実を公式資料などで裏付け、出典を表示する運用を推奨します。
- 本サイトは静的HTML/CSS/JavaScriptです。データ更新管理画面やサーバー側データベースは含みません。

## デザインテーマ
日本代表「なでしこジャパン」をイメージし、ジャパンブルー／ネイビーを主役に、桜を思わせるピンクをアクセントにした配色です。
